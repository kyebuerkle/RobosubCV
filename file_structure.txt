Preparing a MicroSD Card for GoPro and RoboSub Use

Purpose:

This procedure explains how to prepare a MicroSD card for use in a GoPro action camera and for RoboSub dataset collection. It includes formatting the card, verifying the default GoPro folder structure, creating the additional folders needed for data collection and preparation, and copying the data ingestion script from GitHub onto the card.

Warning:

Reformatting a MicroSD card will erase all data currently stored on the card. Before formatting, save any videos, images, or other files you want to keep onto your laptop.

Requirements:

- MicroSD card
- SD card adapter or card reader, if needed
- Laptop or desktop computer
- GoPro action camera
- Charged GoPro battery, if formatting in the camera
- Access to the team GitHub repository containing the data ingestion script

Recommended Card Note:

Use a MicroSD card with enough storage capacity and write speed for GoPro video recording. Before formatting, make sure the card is compatible with the GoPro camera being used.

Official GoPro article on formatting an SD card:
https://community.gopro.com/s/article/SD-Card-Reformat-on-a-Mac-Computer?language=en_US

Formatting the Card on a Computer:

1. Open File Explorer
2. Right-click on the MicroSD card
3. Select Format
4. Make sure the correct file system is selected:
   FAT32 for cards 32 GB or smaller
   exFAT for cards 64 GB or larger
5. Select Quick Format
6. Click Start

Formatting the Card in a GoPro Camera:

If possible, the MicroSD card should be formatted using the GoPro camera itself. Formatting in the camera ensures that all existing data is removed, the card is set to the correct file system, and the necessary GoPro folders are created automatically. This also helps reduce the risk of stray or incompatible files remaining on the card.

For GoPro Hero 4 and Earlier:

1. Turn on the camera
2. Press the Mode button on the front of the camera until the Setup menu appears on the front screen
3. Press the Shutter/Select button to enter the Setup menu
4. Press the Mode button until the trash can icon appears
5. Press the Shutter/Select button
6. Use the Mode button to select ALL/FORMAT
7. Select DELETE
8. The MicroSD card is now formatted

For GoPro Hero 5 and Later:

1. Turn on the camera
2. Swipe down on the touchscreen
3. Select Preferences
4. Scroll down to Format SD Card
5. Select it
6. Choose DELETE or FORMAT
7. The MicroSD card is now formatted

Default GoPro Folder Structure:

After formatting, the GoPro creates two main folders on the MicroSD card:
DCIM
MISC

The MISC folder contains information related to the MicroSD card and the GoPro. The DCIM folder contains the 100GOPRO folder, which is where captured videos and images are stored.

Post-Format Verification:

After formatting is complete:
1. Reinsert the MicroSD card into the camera or computer if needed
2. Confirm that the card is readable
3. Confirm that the DCIM and MISC folders appear
4. Confirm that the card is ready for use before creating the RoboSub folder structure

RoboSub Competition Folder Structure:

For RoboSub use, an additional dataset folder system should be created on the MicroSD card to support video storage, sorting, frame extraction, and data preparation.

The folder structure should be:

RoboSub_Dive_Capture
  640x480_frames
  all_objects
  raw_videos
  rejected_frames
  renamed_sorted
  Scripts_RBSTrain
  section_1
  section_2
  section_3
  section_4
  section_5
  section_6
  section_7

Creating the RoboSub Folder Structure:

After formatting:
1. Open the MicroSD card in File Explorer
2. Create a folder named RoboSub_Dive_Capture
3. Inside RoboSub_Dive_Capture, create the following subfolders:
   640x480_frames
   all_objects
   raw_videos
   rejected_frames
   renamed_sorted
   Scripts_RBSTrain
   section_1
   section_2
   section_3
   section_4
   section_5
   section_6
   section_7

Adding the Data Ingestion Script from GitHub:

After the RoboSub_Dive_Capture folder structure has been created:
1. Open the team GitHub repository containing the data ingestion script
2. Download or clone the required script files from the repository
3. Inside RoboSub_Dive_Capture, create a folder called Scripts_RBSTrain
4. Copy the data_ingestion.py script into the Scripts_RBSTrain folder
5. Confirm that the script copied successfully

Folder Purpose:

640x480_frames - stores resized extracted frames
all_objects - stores combined object data
raw_videos - stores original captured videos
rejected_frames - stores discarded frames
renamed_sorted - stores renamed and sorted files
Scripts_RBSTrain - stores the data ingestion script and related support files
section_1 through section_7 - used during the data preparation procedure

Naming Convention Notes:

Use consistent folder names and file names throughout the dataset. Folder names and file names should not contain spaces if they will be used with automated scripts. Spaces can cause parsing problems or require extra handling in scripts. To reduce the chance of errors, use simple names with letters, numbers, and underscores only. Avoid special characters when possible.

Examples:
raw_videos
rejected_frames
section_1
yellow_buoy_1.mp4
green_buoy_2_frame_015.png
data_ingestion.py

This no-spaces rule also applies to any script files or supporting files copied from GitHub onto the MicroSD card.

Do not rename folders after the folder structure has been created, especially if scripts or later procedures depend on the original names.

During the data collection procedure, subfolders should be created inside 640x480_frames and renamed_sorted for each object class captured in the pool.

Before You Start Checklist:

Before beginning, confirm the following:
- Any important files on the MicroSD card have been backed up
- The correct MicroSD card has been selected
- The GoPro battery is charged if formatting in the camera
- The MicroSD card is compatible with the GoPro being used
- A laptop is available for creating the RoboSub folder structure
- Access to the team GitHub repository is available
- The required data ingestion script files have been identified

Common Mistakes:

- Formatting the wrong drive by accident
- Forgetting to back up files before formatting
- Selecting the wrong file system
- Forgetting to verify that the GoPro folders were created
- Placing dataset files outside the required folder structure
- Using spaces in file names or folder names that will be processed by scripts
- Renaming folders after scripts or procedures have already been set up
- Forgetting to copy the required data ingestion script onto the card

Troubleshooting:

If the MicroSD card is not recognized by the GoPro:
- Reinsert the card and restart the camera
- Check that the correct file system was used
- Format the card again using the GoPro camera if possible
- Make sure the MicroSD card is compatible with the GoPro model

If the data ingestion script does not work correctly:
- Confirm that the script file name was not changed
- Confirm that there are no spaces in folder names or file names
- Confirm that the script was copied to the correct location
- Confirm that all required support files from GitHub were also copied

Safe Removal:

After formatting or editing files on the MicroSD card, safely eject the card from the computer before removing it. This helps prevent file corruption.

Expected Result:

After completing this procedure, the MicroSD card should:
1. Be formatted in a file system compatible with the GoPro
2. Contain the default GoPro folders DCIM and MISC
3. Contain the RoboSub_Dive_Capture folder
4. Contain all required subfolders for data collection and preparation
5. Contain the required data ingestion script files if they are meant to travel with the card
6. Be ready for capturing and organizing RoboSub competition footage
